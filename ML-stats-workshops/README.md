A collection of Jupyter notebooks from a machine learning workshop. Covers introductory supervised and unsupervised learning concepts 
through hands-on exercises and experiments.

Topics
* Fundamentals – Logistic regression, Support Vector Machines (SVM), and Random Forests.
* Clustering – Unsupervised learning exercises.
* Decision Trees – Decision tree models and exercises.
* Keras Image Classification – Image classification using Keras.
